Projet de fin d'études 2026

CityTaste

Plateforme de recommandation de restaurants et d'hébergements à Ottawa, avec un assistant IA qui guide l'utilisateur.

  • Pipeline de données (nettoyage, enrichissement, EDA) versionné avec DVC.
  • Moteur de recommandation et API FastAPI, interface web en HTML/CSS/JS.
  • Assistant conversationnel avec RAG sur la documentation du site et LLM local via Ollama.
  • Banc d'essai de modèles (Gemma 3 4B, Qwen 3 4B, llama.cpp) pour choisir le meilleur compromis qualité/latence.

Assistant RAG — Hôtel

Assistant pour le personnel d'un hôtel d'Ottawa qui répond à partir des documents internes (politiques, procédures, convention collective).

  • Index FAISS + embeddings MiniLM, génération avec Llama 3.2 3B quantifié (GGUF).
  • Fine-tuning QLoRA de Qwen2.5 pour reproduire le ton de l'hôtel, comparé au RAG.

Commandes vocales — GRU

Reconnaissance de mots-clés (yes, no, up, down, go, stop…) sur le Google Speech Commands Dataset.

  • Pipeline audio → MFCC (40 coef.) → réseau GRU, 12 classes.
  • ~91 % de précision sur le jeu de test.
  • Démos : Gradio (micro) et une tortue Python pilotée à la voix.
