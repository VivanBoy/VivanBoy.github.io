## Technique
Site statique (HTML/CSS/JS, sans dépendance JavaScript ni outil de build ; polices chargées depuis Google Fonts), bilingue FR/EN, thème clair/sombre, hébergé sur GitHub Pages.
Le texte français est dans `index.html` ; la traduction anglaise est dans `script.js` (objet `EN`, mêmes clés que les attributs `data-i18n` ; `**texte**` s'affiche en gras).
